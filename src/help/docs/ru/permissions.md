# Права доступа и роли

Доступ определяется **ролью по умолчанию**, при необходимости **отдельной ролью на бакет** и списком бакетов (или облаков), разрешённых для вашей учётной записи. Если действие недоступно или возвращается *access denied* — обратитесь к администратору.

## Как применяются роли

- У каждого пользователя есть **роль по умолчанию** (`admin`, `storage_admin`, `storage_editor`, `storage_viewer` или пользовательская).
- В **Настройки → Пользователи** администратор может назначить **другую роль на конкретный бакет**; она действует только в этом бакете.
- Роль **admin** всегда имеет полный доступ ко всем разрешённым бакетам и открывает **все** вкладки **Настройки**.
- Роль **storage_admin** имеет те же права на объекты и `add_bucket`, что и admin; открывает **Настройки → только Бакеты** (свои созданные бакеты: просмотр и правка настроек). Удаление бакетов — только у admin.
- Чтобы бакет отображался в списке, он должен быть выдан аккаунту (allowed buckets / clouds) или создан вами (auto-grant).

## Встроенные роли

- **admin** — полный доступ к настройкам и полные операции с объектами (включая `preview` и `add_bucket`).
- **storage_admin** — полные операции с хранилищем как у admin; **Настройки → Бакеты** для своих бакетов (`created_by`); Bucket ID только автогенерация.
- **storage_editor** — загрузка, скачивание, предпросмотр, удаление, копирование, перемещение, создание папок, ACL (в назначенных бакетах).
- **storage_viewer** — просмотр списка, предпросмотр и скачивание файлов.

## Пользовательские роли

В **Настройки → Роли** администратор создаёт роли с любым набором прав из списка ниже. Встроенные роли тоже можно менять (кроме **admin** — её может редактировать только пользователь `admin`).

Роль назначается как глобальная по умолчанию или как override на бакет в **Настройки → Пользователи**.

## Чеклист прав (Настройки → Роли)

### Добавление

| Права | Описание |
|-------|----------|
| add_bucket | Регистрация нового бакета (меню **+** и Настройки → Бакеты). Для не-admin открывает Settings → Buckets. Создателю выдаётся доступ; Bucket ID генерируется на сервере. |

### Копирование

| Права | Описание |
|-------|----------|
| copy_file | Копирование одного файла |
| copy_files_multi | Копирование нескольких выбранных файлов |
| copy_folder | Копирование одной папки (рекурсивно) |
| copy_folder_multi | Копирование нескольких выбранных папок |

Для копирования также нужно `upload_files` хотя бы на один бакет назначения (для папок — ещё `upload_folder` или `create_folder`). Массовое право (`*_multi`) достаточно и для одного объекта.

### Загрузка

| Права | Описание |
|-------|----------|
| upload_files | Загрузка файлов |
| upload_folder | Загрузка папки с рабочего стола (сохраняется структура каталогов) |

### Перемещение

| Права | Описание |
|-------|----------|
| move_file | Перемещение одного файла (также нужны delete_file и upload_files на назначении) |
| move_files_multi | Перемещение нескольких файлов (также нужны delete_files_multi и upload_files на назначении) |
| move_folder | Перемещение одной папки (также нужны delete_folder и upload на назначении) |
| move_folder_multi | Перемещение нескольких папок (также нужны delete_folder_multi и upload на назначении) |

### Редактирование

| Права | Описание |
|-------|----------|
| edit_file_acl | Просмотр и изменение S3 ACL объекта (свойства файла, контекстное меню для одного файла и массовый ACL в режиме выбора; для папок ACL применяется рекурсивно ко всем файлам внутри) |

### Скачивание

| Права | Описание |
|-------|----------|
| download_file | Скачивание одного файла |
| download_files_multi | Скачивание нескольких выбранных файлов (режим выбора) |
| download_folder | Скачивание папки как ZIP-архива |

### Предпросмотр

| Права | Описание |
|-------|----------|
| preview | Открытие изображений, PDF, JSON, TXT, MD, HTML и CSS в новой вкладке (`/files/view/...`). Независимо от `download_file`. Общая ссылка view всё равно требует вход, это право и доступ к бакету. |

### Создание

| Права | Описание |
|-------|----------|
| create_folder | Создание пустой папки |

### Удаление

| Права | Описание |
|-------|----------|
| delete_file | Удаление одного файла |
| delete_files_multi | Удаление нескольких выбранных файлов |
| delete_folder | Удаление одной папки (рекурсивно) |
| delete_folder_multi | Удаление нескольких выбранных папок |

## Режим выбора и права

- Чтобы включить **Выбрать** для файлов, обычно нужно хотя бы одно право с суффиксом «несколько» (скачивание, удаление, копирование, перемещение) или `edit_file_acl`.
- Для выбора **папок** при copy/move/delete нужно соответствующее право на папку или массовое; для **массового ACL** достаточно `edit_file_acl`.
- **Скачивание** одного файла — `download_file` или `download_files_multi` (multi достаточно и для одного); несколько файлов — `download_files_multi`. Папки в массовое скачивание не входят.
- **Контекстное меню файла/папки** использует те же права на одиночный объект (`download_file` / `download_folder`, `copy_file` / `copy_folder` + `upload_files` на назначении, `move_file`+`delete_file` / `move_folder`+`delete_folder` + upload на назначении, `delete_file` / `delete_folder`, `preview`, `edit_file_acl`). Недоступные действия отключены.
