# Бакеты и навигация

- В левой панели — список доступных бакетов. Поле поиска фильтрует по отображаемому имени.
- Откройте бакет кликом; в основной области — папки и файлы текущего пути.
- Новый бакет можно добавить через меню кнопки **+** в тулбаре (**Добавить бакет**, право `add_bucket`) или в **Настройки → Бакеты**.
- **Bucket ID** генерируется на сервере и после создания не меняется.
- После создания бакет **автоматически выдаётся вашей учётной записи** с **ролью по умолчанию**; при необходимости облако тоже добавляется в allowed clouds. Для пользователей с полным доступом (`*`) ничего не меняется. Сайдбар обновляется, и новый бакет сразу появляется в списке.
- В **Настройки → Бакеты** не-admin видит только созданные им бакеты и может править их настройки (удаление — только admin).
- Хлебные крошки над списком ведут в любую родительскую папку или в корень бакета.
- В шапке — размер бакета и число объектов. На больших бакетах расчёт может занять время; иконка обновления запускает пересчёт.
- Пагинация внизу подгружает объекты постранично.
- Пока бакет не выбран, большинство кнопок панели инструментов недоступно.
