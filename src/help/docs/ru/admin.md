# Настройки администратора

**Настройки** (иконка шестерёнки в меню пользователя):

- **admin** — все вкладки (Бакеты, Облака, Пользователи, Роли, Поиск, Статус).
- **storage_admin** или любая роль с `add_bucket` — только вкладка **Бакеты** (созданные этим пользователем).

- **Бакеты** — подключение S3: endpoint, учётные данные, отображаемое имя, TLS и CA. Добавить бакет также можно из меню кнопки **+** (`add_bucket`). При создании пишется `created_by`, выдаётся доступ с ролью по умолчанию, **Bucket ID** генерируется на сервере и дальше не меняется. Создатель может смотреть/править настройки своих бакетов; **удаление** — только у admin. Не-admin не может увести endpoint вне allowlist.
- **Облака** — группировка бакетов по провайдеру; endpoint URL и **Enable public URL** (показывать или скрывать **Source URL** в свойствах файла). Только admin.
- **Пользователи** — учётные записи, пароли, глобальные и per-bucket роли. Только admin.
  - При **добавлении** и **копировании** пользователя можно найти человека в AD/LDAP (иконка поиска у логина): минимум 5 символов, частичное совпадение по логину / ФИО / email. Один результат заполняет поля сразу; несколько — список для выбора. При копировании права и списки бакетов/облаков сохраняются, а логин/ФИО/email задаются заново.
  - LDAP включается переменными `LDAP_URI`, `LDAP_BASE_DN`, `LDAP_BIND_USER`, `LDAP_BIND_PASSWORD` (см. README). Нужен `ldaps://` и service account только на чтение.
- **Роли** — встроенные и пользовательские роли с чеклистом прав. Только admin.
- **Поиск** — подключение Meilisearch, индексация по бакетам, переиндексация одного или всех бакетов. Включение/выключение индекса и переиндексация — в заголовке таблицы и в колонках строк (контекстного меню на вкладке Поиск нет). Только admin.
- **Статус** — проверка подключений Database, S3, LDAP, SSO/OIDC и Meilisearch (настроено ли, доступен ли сервис). Если LDAP-поиск в форме пользователя неактивен — смотрите эту вкладку: обычно не заданы `LDAP_URI` / bind-учётка или bind не проходит. Только admin.
- **Контекстное меню (ПКМ)** в строках Users, Roles, Clouds и Buckets: Копировать, Редактировать, Удалить (тот же стиль context-menu, что и в списке файлов). На вкладке **Бакеты** также **Доступ** — кому разрешён бакет и с какой storage-ролью. Edit/Delete могут быть недоступны для защищённых встроенных строк (например роль `admin` или пользователь `admin`). На вкладке Бакеты Delete для не-admin отключён.
