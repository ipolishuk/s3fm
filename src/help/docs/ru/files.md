# Работа с файлами и папками

- Кнопка **+** в тулбаре открывает меню действий (пункты зависят от прав):
  - **Добавить бакет** — право `add_bucket` (если права нет, пункт не показывается);
  - **Создать папку** — право `create_folder`;
  - **Загрузить файлы** — право `upload_files`, либо перетаскивание в список;
  - **Загрузить папку** — право `upload_folder`, либо drag-and-drop папки с рабочего стола.
- **Контекстное меню (ПКМ)** по строке файла или папки открывает те же действия, что ниже. Пункты без нужного права отключены или скрыты; в режиме выбора активные пункты применяются ко всем выбранным элементам. Preview и Properties доступны только если выбран ровно один файл.
  - **Файл:** Скачать (`download_file`), Копировать (`copy_file` + `upload_files` на назначении), Переместить (`move_file` + `delete_file` + upload на назначении), Удалить (`delete_file`), Предпросмотр (`preview`, только для поддерживаемых типов), Свойства (диалог свойств файла), Изменить ACL (`edit_file_acl`, то же окно, что массовый ACL, для одного файла).
  - **Папка:** Скачать ZIP (`download_folder`), Копировать (`copy_folder` + upload на назначении), Переместить (`move_folder` + `delete_folder` + upload на назначении), Удалить (`delete_folder`), Изменить ACL (`edit_file_acl`, применяется рекурсивно ко всем файлам внутри). Предпросмотр и Свойства для папок не показываются.
- **Предпросмотр** — из контекстного меню или кнопки в свойствах файла; открывает новую вкладку (`/files/view/...`). Поддерживаются JPEG, PNG, GIF, WebP, BMP, PDF, JSON, TXT, MD, HTML, CSS. Нужны право `preview` (отдельно от `download_file`) и доступ к бакету. HTML отдаётся в sandbox (без скриптов); Markdown — как текст.
- **Скачивание** — из контекстного меню. Файл скачивается напрямую (`download_file`); папка упаковывается в ZIP (`download_folder`).
- Клик по **строке файла** открывает свойства; клик по **строке папки** — переход в папку.
- **Копирование** и **перемещение** — из контекстного меню для одного объекта или массово в режиме выбора; в диалоге укажите бакет и путь назначения.
- **Удаление** — из контекстного меню или массово; перед удалением запрашивается подтверждение.
- Загрузка, удаление, копирование, перемещение и массовый ACL отображают прогресс. Активные задачи сохраняются при обновлении страницы и подключаются заново.
