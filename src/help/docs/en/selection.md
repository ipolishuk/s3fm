# Selection mode and bulk actions

- Click **Select** on the toolbar to show checkboxes in the file list.
- **Select all** in the column header marks every item on the current page. If there are more pages, use the link in the header to select all items in the bucket or folder.
- In selection mode, bulk Download, Copy, Move, Delete, and ACL are available from the **context menu (right-click)** on selected items where permitted.
- Bulk ACL applies to selected files. Selected folders include all files inside them recursively.
- With `edit_file_acl` you can select files and folders for bulk ACL even without copy or delete permissions.
- Whether you can select files, folders, or both for other actions depends on your role permissions.
- Click **Cancel** or press **Esc** to exit selection mode without changes.
