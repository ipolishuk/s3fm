# Свойства файла и ACL

- Свойства открываются кликом по **строке файла** или через контекстное меню (**Свойства**). У папок диалога свойств нет.
- **Предпросмотр** — из свойств или контекстного меню файла; открывает поддерживаемые типы в новой вкладке при наличии права `preview` (см. [Работа с файлами](files.md)).
- Отображаются: имя, размер, content-type, даты создания и изменения, метаданные пользователя (если есть) и **Source URL** — при включённой опции для облака (см. настройки облака у администратора).
- **Source URL** — прямая ссылка на объект (`https://{endpoint}/{bucket}/{key}`), открывается в новой вкладке. Доступность файла по ссылке зависит от политики бакета и ACL объекта в S3. Если для облака выключен **Enable public URL**, в свойствах показывается прочерк (—).
- Блок **ACL** — список grants (получатель и разрешение). Просмотр требует доступа к бакету; редактирование — право `edit_file_acl` и поддержку ACL на стороне S3.
- **Изменить ACL** в контекстном меню файла или папки (`edit_file_acl`). Для папки ACL применяется рекурсивно ко всем файлам внутри. В режиме выбора — ко всем выбранным элементам.
- Массовое редактирование ACL для выбранных файлов и папок доступно через контекстное меню при наличии права `edit_file_acl`.
- При выборе папки ACL применяется рекурсивно ко всем файлам внутри неё (включая вложенные подпапки).
- Массовое применение ACL выполняется в фоне с индикатором прогресса. При обновлении страницы задача подключается заново и прогресс продолжается.
