# Interface and account

- **User menu** (top right): profile, Settings (admin — all tabs; `storage_admin` / `add_bucket` — Buckets only), Help, language, theme, log out.
- **Profile** shows login, email, role, account creation date, and last login.
- Help URLs: `/help/documentation` and `/help/support`; browser Back works between sections.
- File manager URLs: `/bucket-id/path/to/folder` — suitable for bookmarks and deep links.
- **Right-click** a file or folder in the list for Download, Delete, Preview, and Properties (see [Working with files](files.md)).
