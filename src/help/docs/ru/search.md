# Поиск

- Поле поиска над списком ищет объекты по имени в текущем бакете.
- При включённой индексации Meilisearch поиск быстрый по всему дереву бакета.
- Без Meilisearch выполняется обход S3 — на больших бакетах это медленнее.
- Очистите поле (×) или оставьте пустым, чтобы вернуться к обычному просмотру папки.
- Администраторы управляют индексацией в **Настройки → Поиск** (статус, вкл/выкл по бакету, переиндексация).
