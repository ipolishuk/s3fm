# Режим выбора и массовые операции

- Кнопка **Выбрать** на панели включает чекбоксы в списке файлов.
- **Выбрать все** в заголовке колонки отмечает элементы на текущей странице. Если есть другие страницы, по ссылке в заголовке можно выбрать все элементы в бакете или папке.
- Панель выбора: массовые действия (скачивание, копирование, перемещение, удаление, ACL) доступны через **контекстное меню (ПКМ)** по выбранным элементам при наличии прав.
- Массовый ACL применяется к выбранным файлам. Выбранные папки включают все файлы внутри них рекурсивно.
- С правом `edit_file_acl` можно выбирать файлы и папки для массового ACL без прав на копирование или удаление.
- Можно ли выбирать файлы, папки или оба типа для других действий — зависит от прав роли.
- **Отмена** или клавиша **Esc** выходят из режима выбора без изменений.
