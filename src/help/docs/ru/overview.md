# Обзор

S3 File Manager — веб-интерфейс для работы с S3-совместимыми хранилищами (AWS S3, MinIO и аналоги).

После входа отображаются бакеты, доступные вашей учётной записи. Права проверяются для каждого бакета и каждого действия — недоступные операции скрыты или отключены.

Поддерживаются русский и английский языки, светлая и тёмная темы, навигация через URL (бакет и путь к папке в адресной строке) для закладок и ссылок.
