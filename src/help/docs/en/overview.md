# Overview

S3 File Manager is a web interface for managing objects in S3-compatible storage (AWS S3, MinIO, and similar backends).

After sign-in you see buckets your account may access. Permissions are enforced per bucket and per action — unavailable operations are hidden or disabled.

The UI supports Russian and English, light and dark themes, and URL-based navigation (bucket and folder path in the address bar) for bookmarks and sharing links.
