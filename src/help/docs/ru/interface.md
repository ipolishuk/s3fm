# Интерфейс и учётная запись

- **Меню пользователя** (справа вверху): профиль, Настройки (admin — все вкладки; `storage_admin` / `add_bucket` — только Бакеты), Справка, язык, тема, выход.
- **Профиль** — логин, email, роль, дата создания и последний вход.
- URL справки: `/help/documentation` и `/help/support`; кнопка «Назад» в браузере работает между разделами.
- URL файлового менеджера: `/bucket-id/путь/к/папке` — удобно для закладок и прямых ссылок.
- **ПКМ** по файлу или папке в списке — Скачать, Удалить, Предпросмотр, Свойства (см. [Работа с файлами](files.md)).
