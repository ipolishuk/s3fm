# Buckets and navigation

- The left panel lists buckets available to you. Use the search field to filter by display name.
- Click a bucket to open it; folders and files appear in the main list.
- Add a new bucket from the toolbar **+** menu (**Add bucket**, requires `add_bucket`) or in **Settings → Buckets**.
- **Bucket ID** is generated on the server and cannot be changed after creation.
- When you create a bucket, it is **automatically granted to your account** with your **default role**, and the cloud is added to your allowed clouds if needed. Users with full access (`*`) are unchanged. The sidebar refreshes so the new bucket appears immediately.
- In **Settings → Buckets**, non-admin users see only buckets they created and can edit their settings (delete is admin-only).
- Breadcrumbs above the list jump to any parent folder or the bucket root.
- The toolbar shows bucket size and object count. On large buckets calculation may take time; click the refresh icon to recalculate.
- Pagination at the bottom loads objects page by page.
- Until a bucket is selected, most toolbar actions stay disabled.
